# Frais médicaux cem - backend
## Descrption
```text
Un système de suivi de facturation des personnels de la Caisse d'Epargne de Madagascar.
Ce système offre la gestion des personnels, la gestion des prestataires, la gestion de bénéficiaire, la gestion des prises en charges, et la gestion des factures au nom du CEM.
```

### Stack 
Les stacks utilisés pour le développemnet du projet(Backend) sont :
- Nest.JS
- Prisma
- PostgreSQL
